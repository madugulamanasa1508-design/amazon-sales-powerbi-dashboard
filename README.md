# Amazon Sales Power BI Dashboard

## Project Overview

This project is an interactive Amazon Sales Dashboard developed using Microsoft Power BI.

The dashboard provides a visual analysis of sales performance using KPIs, interactive charts, and slicers to help users explore the data from different perspectives.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dashboard Features

- Interactive KPI cards
- Sales performance analysis
- Interactive charts and visualizations
- Slicers for filtering the dashboard
- Category and product-level analysis
- Interactive exploration of sales data

## Key Components

### KPIs
The dashboard includes key performance indicators to provide a quick overview of sales performance.

### Visualizations
Charts are used to identify sales trends and compare performance across different categories and dimensions.

### Slicers
Interactive slicers allow users to filter the dashboard and analyze specific portions of the sales data.

## Data Preparation

The project uses sales data as the underlying dataset. The data is analyzed and visualized using Power BI.
